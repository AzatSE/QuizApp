## Остаточные риски (принято осознанно)

1. **PIN из 6 цифр** можно перебирать. Смягчение: вход только в фазе лобби, rate-limit 60 POST/мин на IP, злоумышленник попадёт лишь в лобби (правильные ответы недоступны). Для публичных игр можно увеличить длину PIN.
2. **Rate-limit в памяти процесса** (`LocMemCache`): при нескольких воркерах лимит считается раздельно. Для продакшена с масштабированием — Redis (`CACHES`).
3. **Много игроков за одним NAT** (класс/школа) делят IP-лимит; лимиты выставлены с запасом (600 ответов/мин).
4. **Polling раз в секунду** — нагрузка растёт линейно с числом игроков; для >200 одновременных игроков стоит перейти на Django Channels.
5. **HSTS preload** (`W021`) не включён: preload необратим, включайте сами после проверки домена.
6. Игры и ники игроков хранятся до `cleanup_games`; персональных данных, кроме ника и логина ведущего, нет.
